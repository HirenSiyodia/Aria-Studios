# 🎨 Aria Studios

A modern and creative **artist portfolio website** built with **React, Tailwind CSS, and React Router DOM**.

Aria Studios is designed as a visually focused portfolio website for showcasing creative work such as **Digital Art, Illustration, UI/UX Design, Motion Graphics, and 3D/Animation projects**.

The project focuses on creating a clean, modern, and interactive user experience while keeping the code organized into reusable React components.

---

## ✨ Features

* 🎨 Modern and creative portfolio design
* 🏠 Home page with hero section
* 🖼️ Featured works section
* 🎭 Portfolio gallery with category filtering
* 🔍 Portfolio categories:

  * All
  * Digital Art
  * Illustration
  * Design
  * Animation
* 📄 Dedicated About page
* 📬 Contact page
* 🧭 Client-side navigation using React Router DOM
* 🔗 Navigation between multiple pages without full page reloads
* 🎯 Reusable React components
* ✨ Hover effects and interactive UI elements
* 🌈 Gradient text and modern visual styling
* 📱 Responsive layout for different screen sizes
* 🦶 Reusable footer with social links and quick navigation
* ⚡ Fast development and build setup using Vite

---

## 🛠️ Technologies Used

### Frontend

* **React.js** – Building the user interface
* **JavaScript (ES6+)** – Application logic
* **React Router DOM** – Client-side routing
* **Tailwind CSS** – Styling and responsive layouts
* **React Icons** – Icons throughout the application
* **Vite** – Development server and build tool

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/HirenSiyodia/Aria-Studios.git
```

### 2. Navigate into the project

```bash
cd Aria-Studios
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available on the local development server provided by Vite.

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
